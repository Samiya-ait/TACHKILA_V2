# TACHKILA_V2
L'application offre une interface interactive pour gérer les joueurs, composer une équipe selon différentes formations tactiques et suivre les informations relatives aux matchs.

## Technologies Utilisées
* **HTML5** 
* **Tailwind CSS** 
* **JavaScript (DOM)** 
* **LocalStorage** 
* **ES6 Modules** 
## Structure du projet JavaScript
```text
TACHKILA_V2/
│
├── js/
│   ├── data.js
│   ├── effectif.js
│   └── functions.js
│
├── index.html
└── README.md
```
## Fonctionnalités Implémentées

* 1.Affichage des joueurs sous forme de cartes contenant leur numéro, nom, poste, âge et statut (En forme / Blessé).
* 2.Identification visuelle des postes grâce à une bordure colorée sur chaque carte.
* 3.Ajout d'un joueur via une fenêtre modale.
* 4.Modification des informations d'un joueur.
* 5.Suppression d'un joueur avec une confirmation avant l'action.
* 6.Validation des formulaires en temps réel à l'aide de Regex
* 7.Recherche d'un joueur par son nom.
* 8.Filtrage des joueurs par poste.
